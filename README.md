# UNIVERSO SMA70

Una sala de criterio minimalista para observar el mercado con método, distancia y calma.

## Arquitectura

- **COLOR SMA70** conectado en vivo a `bolsa15/data/jornada.json`.
- **Relojes** de Nueva York, Madrid y Tokio.
- **70 PRINCIPIOS** presentados como baraja horizontal.
- **ZONA DE INVESTIGACIÓN** con el mismo PIN simbólico y datos vivos del RADAR SMA70 de BOLSA15.
- **DIFÍCIL DE MOVER** integrado como acceso externo de criterio y posición.

## Publicación

El sitio es estático y autocontenido. Su entrada es `index.html`, por lo que puede publicarse directamente mediante GitHub Pages o conectarse a ChatGPT Sites.

## Fuente de datos

Los contenidos dinámicos se leen desde:

- `https://raw.githubusercontent.com/joaquinzapatagarcia/bolsa15/main/data/jornada.json`
- `https://raw.githubusercontent.com/joaquinzapatagarcia/bolsa15/main/data/principios.json`
- `https://raw.githubusercontent.com/joaquinzapatagarcia/bolsa15/main/data/radar-sma70.json`

Los datos y el análisis no constituyen asesoramiento financiero personalizado.
